# Agentic Workbench

A growing collection of Python notebooks exploring AI agents that connect language models with tools, data, and executable workflows.

The implementations explore how agents select tools, handle structured inputs, and use execution results to complete tasks.

## Scope

- **Tool calling:** Manual and model-driven invocation of Python functions.
- **Custom tools:** Defining tool interfaces, input schemas, and task-specific behavior.
- **Workflow composition:** Connecting prompts, models, tools, and output parsers with LangChain Expression Language (LCEL).
- **Output validation:** Parsing structured responses and validating tool arguments.
- **Data analysis and visualization:** Using natural language to explore tabular data and generate charts.
- **Conversational SQL:** Querying relational databases through LangChain agents.

## Stack

Python · Jupyter Notebook · LangChain · LCEL

Additional dependencies and model configuration are documented within individual notebooks.

## Getting Started

1. Open a notebook in JupyterLab or VS Code.
2. Install the dependencies specified in the notebook.
3. Configure any required API credentials using environment variables.
4. Run the cells to inspect the workflow and its outputs.

## Status

Work in progress. Notebooks are added and refined as implementations develop.
